# Incoming model drops

Drop new, unassigned models here. This is an intake folder, excluded from the
runtime model build. Once reviewed, move the untouched master to its canonical
category folder. Do not keep a second copy here.

Ship skins: `../ships/skins/<skin-name>/model.glb`.
Probe skins: `../probes/<name>.glb`.
Generated models and product renders belong in `apps/web/public/assets/`.
The four original ship drops are now under `ships/skins/`.
